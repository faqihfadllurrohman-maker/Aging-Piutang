Gratis dari Google Firebase

Cukup salin dan tempelkan blok firebaseConfig = { ... } langsung dari Firebase Console.

Cara Mendapatkan Firebase Config (3 Menit):

  1. Buka console.firebase.google.com (login pakai akun Google Anda).
  2. Klik "Add project" > Beri nama (misal: invoice-hub) > Klik Lanjutkan.
  3. Di menu kiri, klik Firestore Database > Create database > Pilih mode "Start in test mode" > Klik Create.
  4. Klik ikon gerigi ⚙️ (Project settings) > Gulir ke bawah ke bagian "Your apps" > Klik ikon Web </> > Salin kode firebaseConfig dan tempelkan di kotak di atas.
